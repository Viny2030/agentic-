# Agente Híbrido: Cómputo Cuántico y Datos (Claude Engine)

Sistema agéntico optimizado para costos reducidos con Claude 3.5 Haiku, soporte de Prompt Caching y herramientas híbridas (NumPy + Qiskit Aer).

## Estructura
- `app.py`: Aplicación principal con interfaz Gradio y ciclo de herramientas.
- `requirements.txt`: Dependencias del proyecto.
- `.env.example`: Plantilla de credenciales.

## Ejecución
1. Instalar dependencias: `pip install -r requirements.txt`
2. Exportar clave: `export ANTHROPIC_API_KEY="tu_clave"`
3. Iniciar chat: `python app.py`
